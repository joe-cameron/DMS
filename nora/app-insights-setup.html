Setting Up Azure Application Insights

Nora's guide — follow each step in order. Check them off as you go.

Part 1: Create the App Insights Resource
1

Open Azure Portal

Go to the Azure Portal in your browser:

https://portal.azure.com

Sign in with your jcameron@decades-cg.com account.

2

Create a New Application Insights Resource

In the search bar at the top, type "Application Insights" and click on it.

Click the + Create button.

Fill in these fields:

Your Azure subscription
Create new → "DCFG-Monitoring"
dcfg-app-insights
East US (same as your Dataverse)
Workspace-based
Create new → "dcfg-logs"

Click Review + Create, then Create.

This takes about 30 seconds to deploy.
3

Copy the Connection String

After deployment, click Go to resource.

On the Overview page, find Connection String (not Instrumentation Key — that's the old way).

Click the copy icon next to the Connection String. It looks like this:

InstrumentationKey=abc123...;IngestionEndpoint=https://eastus-8.in.ai...

Save this — you'll need it in Step 4.

You actually need just the InstrumentationKey part (the GUID after "InstrumentationKey="). It looks like: a1b2c3d4-e5f6-7890-abcd-ef1234567890
Part 2: Connect to Power Pages
4

Add the Site Setting

I'll add this for you automatically. Just paste the Instrumentation Key in the terminal when I ask.

What gets created:

ApplicationInsights/InstrumentationKey
Your key from Step 3

This single setting enables Application Insights on the Power Pages portal. All page views, API calls, and errors start flowing automatically.

5

Clear Portal Cache

After the site setting is created, clear the cache so the portal picks it up:

https://holding.powerappsportals.com/_services/about?clearCache=true

Part 3: See Your Data
6

Wait 5 Minutes, Then Check

Go back to your App Insights resource in Azure Portal.

Click Live Metrics in the left menu — you should see real-time requests if anyone is using the portal.

Click Performance — shows page load times and API call durations.

Click Failures — shows any errors (4xx, 5xx, JavaScript exceptions).

Click Users — shows who's using the portal and when.

7

Useful Queries (Log Analytics)

Click Logs in the left menu. Here are queries you can run:

Page views in the last hour:

pageViews | where timestamp > ago(1h) | summarize count() by name | order by count_ desc

Failed requests:

requests | where success == false | order by timestamp desc | take 20

JavaScript errors:

exceptions | order by timestamp desc | take 20

Slowest pages:

pageViews | summarize avg(duration) by name | order by avg_duration desc

User sessions:

pageViews | summarize count() by user_AuthenticatedId | order by count_ desc

You can pin any of these queries to an Azure Dashboard for a quick-glance view.
What You Get

After Setup, Application Insights Automatically Tracks:

  • Page Views — which screens users visit, how long they stay
  • API Calls — every Dataverse Web API request, timing, success/failure
  • JavaScript Errors — unhandled exceptions in the SPA
  • Server Response Times — how fast Power Pages responds
  • User Sessions — who logged in, when, how long
  • Dependency Calls — external service calls (SharePoint, flows)
  • Browser Performance — load time, rendering, network

Cost: Free tier includes 5 GB/month of data ingestion. For a small team using the DCFG portal, you'll stay well within the free tier.
