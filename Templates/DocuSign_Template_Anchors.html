CONTRACT DOCUMENT

This is a template document for creating a DocuSign template. Upload this to DocuSign, then configure the recipient roles and anchor-based tab placement in the DocuSign template designer.

Instructions:
  1. Open this file in Microsoft Word and Save As .docx
  2. Upload the .docx to DocuSign > Templates > New Template
  3. Define 5 recipient roles: Financial Reviewer (CC), Vendor (Signer), Company President (Signer), Client Signer (Signer), Filing Recipient (CC)
  4. DocuSign will detect the white anchor text below and let you assign tabs to each anchor
  5. Map each anchor to the correct recipient role
  6. Save the template and copy the Template ID to System Admin > dcfg_docusign_template_id
