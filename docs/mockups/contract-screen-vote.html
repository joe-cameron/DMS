Contract Screen Redesign

We're redesigning the contracts screen to handle thousands of contracts and make it faster to find what you need. We'd like your input on the layout direction.

Review the 3 options below and pick your favorite

How This Works

Below are three layout concepts for the new contracts screen. Each one shows the same data and the same creation options — they just organize it differently.

  • All three have a "+ New" dropdown for creating Work Orders, Amendments, and Vendor MSAs
  • All three show document links directly — no extra clicks to find a signed document
  • All three default to showing contracts that need attention, with a toggle to see everything
  • Scroll down to vote for your favorite — you can also leave notes

How It Works

Click any row to expand it inline — see contractor, vendor, location, dates, and document link without navigating away. Click again to collapse. Create any contract type from the "+ New" dropdown.

Default View

Shows contracts needing attention — unsigned, in approval, or recently generated. One click to see all active. Server-side pagination handles thousands.

Document Access

Document link appears in the expanded detail. One click from the list — no need to open the full detail page to find a signed document.

Strengths

  • Familiar spreadsheet feel
  • See details without losing your place
  • Easy to scan many rows quickly

Trade-offs

  • Expanded rows push content down
  • One row expanded at a time

How It Works

Contracts grouped under their customer. Click a customer header to collapse/expand. Programs shown inline per row. Document icons visible directly on each row — click to open the signed document.

Default View

Only customers with contracts needing attention are shown. Toggle to see all customers. Create any contract type from the "+ New" dropdown.

Document Access

Document icon appears directly on each row. If a document exists, one click opens it. No expanding, no detail page needed.

Strengths

  • Matches how you think: "Show me Bancroft"
  • Natural grouping by program
  • Doc links visible immediately

Trade-offs

  • Can't sort across all contracts
  • Many open groups = scrolling

How It Works

Left panel always shows contracts needing your attention. Right panel is dedicated search — find any contract across the entire system. Both panels show document links inline. Create any contract type from the "+ New" dropdown.

Default View

Both panels visible at all times. Left auto-refreshes with attention items. Right starts empty until you search.

Document Access

Document links appear on every card in both panels. Signed documents are always one click away.

Strengths

  • Action items always visible
  • Search doesn't interfere with queue
  • Clean separation of workflows

Trade-offs

  • Less screen space per panel
  • Cards show less data per item
