Key Concepts

  • Vendor and Customer are mutually exclusive at the top level — a record is one or the other. Vendors own Customers.
  • MSAs are entity-level agreements (Customer + Vendor). No location reference — no Property FK.
  • Contracts (Work Orders) are location-level — they reference both an MSA (terms) and a Property (site).
  • Amendments are Contracts that self-reference a parent Contract. dcfg_amendment_number tracks the version.
  • MSA Rates set pricing per Location Type per MSA. Location Types are shared reference data.
  • Document Generation is triggered by writing to dcfg_document_request. Power Automate picks it up via Dataverse trigger.
  • dcfg_customer is the most-connected table — referenced by Sales, Contracts, Locations, Onboarding, and Operations.
