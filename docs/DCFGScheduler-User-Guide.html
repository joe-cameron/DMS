1. What This Tool Does

The DCFG Scheduler reads live inspection data from UpKeep (synced every 30 minutes) and optimizes future inspection schedules across all customers. It answers three questions:

  1. What's already scheduled? — Calendar tab shows confirmed UpKeep work orders
  2. What should be scheduled next? — Optimization Planner suggests efficient routes
  3. What data needs fixing? — Data Issues tab flags missing coordinates, customer assignments, etc.

The tool does NOT write back to UpKeep. UpKeep is read-only. The optimizer's suggestions are proposals — a human reviews them and creates the work orders in UpKeep.

2. Business Rules & Assumptions

90-Day Cadence (±5 Days)
Every location gets inspected 4 times per year. The target interval between inspections is 90 days. The optimizer can schedule within a ±5 day window (85–95 days from last inspection). 85 days is preferred over 95 — schedule early in the window when possible, only push later if geography demands it.
RuleValueNotes
Inspections per year4Quarterly, ~90 days apart
Eligible window85–95 days from last inspection±5 day flex for route efficiency
First inspection4 hoursNew location, never inspected before
Return inspection1 hourPreviously inspected location
Large facility / Campus4 hours always2+ child locations at same address, or Campus/School type
Max day (combined)8 hoursOn-site time + ALL driving = 8h. No overtime.
Shore traffic blackoutNo shore towns on FridaysMemorial Day through Labor Day. Long Branch and shore corridor.
Weekdays onlyMon–FriNo weekend inspections
UpKeep is READ-ONLY—Never modify UpKeep data. Only read.

What counts as a "location"?

  • Schedulable: Street addresses — houses, apartments, group homes. One visit per address.
  • NOT schedulable: Rooms, closets, dens, hallways, offices, classrooms, storage areas, buildings within a campus. These are sub-units of a property and are covered by the parent visit.
  • Campus = one visit: Lakeside Campus, Welsh Campus School, NewGrange School Campus — one 4-hour inspection covers all buildings at that address.

Inspector load balancing

The optimizer distributes work evenly between inspectors. The inspector with fewer assigned days gets first pick of the nearest cluster each day. Both inspectors should end up with roughly equal total days.

Piggyback optimization

If an inspector already has a scheduled UpKeep day in an area, the optimizer suggests adding nearby eligible locations to that existing trip instead of creating a new day. This reduces total field days.

4. Calendar Tab

1View confirmed inspections

The calendar shows a 3-week view of UpKeep-scheduled inspection days. Solid blue cells = confirmed work. Navigate with ◄ ► arrows or scroll with mouse wheel.

2Click a day for details

Click a blue day cell to open the detail panel on the right showing: inspector, stop list, on-site hours, drive time, total hours, and a Route button.

3Check Needs Inspection below

Scroll down to the Needs Inspection grid. This shows locations that need a new UpKeep work order created — they have no upcoming scheduled inspection within their 90-day window.

5. Optimization Planner Tab

This is where the optimizer's suggested schedule lives. Two view modes:

Calendar View (default)

1Read the day cards

Each card shows a proposed day: date, inspector, stop count, on-site hours, drive time, and combined total (X.Xh / 8h). A capacity bar visualizes utilization:

Green ≥90% · Blue ≥70% · Amber <70%

2Understand the color coding

Each stop has a colored left border and badge:

UPKEEPAlready scheduled in UpKeep — confirmed, respect this
ADD or PROPOSEDOptimizer suggests adding this — not yet in UpKeep

On a piggyback day, you'll see both: blue existing stops + teal proposed additions.

3Click 🗺 Route on any day card

Opens Google Maps with the full round-trip route: inspector home → all stops → home. Verify the route makes sense before creating work orders.

4Click a day card for route detail

The right panel shows numbered stops with: customer, address, location type badge, FIRST/RETURN badge, drive time per leg, eligibility window (85–95 day range), last inspection date, and a View Route in Google Maps button.

5Toggle inspectors

Use the Inspector A / Inspector B buttons in the planner header to filter by inspector. Compare their individual schedules.

List View

Click "List" to see all suggestions in a flat table: customer, location, address, suggested date, inspector, hours, type. Useful for bulk review or CSV export.

6. Data Issues Tab

Shows real data quality problems. Each issue type has a severity badge and a detail table.

IssueSeverityWhat to do

Locations with no customerWARNINGAssign a customer to the property in Dataverse. Without a customer, the location won't appear in customer-filtered views.
No inspection schedule dataCRITICALThe UpKeep sync may not be running. Check the inspectionSync Azure Function in the Azure Portal.

7. Needs Inspection Grid

Located at the bottom of the Calendar tab. Shows locations that do not have an upcoming UpKeep work order but need one based on their 90-day cadence.

Tabs: 30 Days | 60 Days | 90 Days

Locations are bucketed by how soon their next inspection is due. 30 Days = most urgent.

Row colors

NEVERNever been inspected — highest priority
OVERDUEPast the 95-day window — overdue
Normal rowDue within the selected window but not yet overdue

Rows are sorted: overdue/never first, then by days until due (ascending).

If a location is already scheduled in UpKeep, it does NOT appear here. This grid only shows locations that need a NEW work order created.

8. Filters & Parameters

Customer Filter (ticker bar)

Colored buttons for each customer. Click to toggle on/off. Filters all views: calendar, planner, needs inspection, data issues.

Inspector Filter (ticker bar)

Inspector A / Inspector B buttons. Toggle to show/hide each inspector's schedule. Also available in the Planner header.

Scenario Parameters (gear icon ⚙)

Click the gear icon in the ticker to open the scenario drawer. Adjust these sliders to see how they impact the schedule:

ParameterDefaultWhat it controls
First Insp4hHours for a first-time inspection
Return1hHours for a return inspection
Max Day8hHard cap on combined on-site + drive time
Visits/Yr4xRequired inspections per year (drives the 90-day cadence)
Cluster Mi15 miHow far apart locations can be to group on the same day
Max Drive/Stop45 minMaximum drive time between stops (relaxed when day is under 60% full)

Changes to parameters instantly recalculate the optimization planner. The calendar (UpKeep data) is not affected — it shows what IS scheduled, not what the optimizer suggests.

9. Viewing Routes in Google Maps

1From the Planner Calendar

Every day card has a blue 🗺 Route chip in the header. Click it — Google Maps opens with the full route. No need to open the detail panel first.

2From the Route Detail Panel

Click a day card to select it, then click View Route in Google Maps in the detail panel on the right.

3From the Sticky Mini-Panel

When a day is selected, a dark bar sticks to the top of the planner. It has a Route button that stays visible as you scroll.

Route order: The optimizer routes farthest location from inspector home first, then nearest-neighbor back toward home. The inspector ends the day close to where they started.
Addresses include the correct state (NJ, DE, or PA) from Dataverse. If Google Maps routes to the wrong location, check that the property's address and state are correct in Dataverse.

Shore traffic rule

Locations in the NJ shore zone (south of 40.5°N latitude, east of -74.2°W longitude — Long Branch, Asbury Park area) are NOT scheduled on Fridays between Memorial Day and Labor Day due to Garden State Parkway traffic.
